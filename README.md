# Serverless Multi-Cloud Cost Optimizer

A free unified dashboard for monitoring and optimizing cloud spend across AWS, GCP and Azure.

## Stack
- Next.js + TypeScript
- Supabase Auth + PostgreSQL
- FastAPI + Python
- AWS, GCP and Azure provider adapters

## Current phase
Authentication foundation, cloud-account schema, RLS, and provider integration boundaries.

Never commit secrets. Use `.env.example` as the template.
